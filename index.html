Join the Chameleon server

Modded Survival · NeoForge 1.21.1 · Mods download automatically with AutoModpack

The short version: install NeoForge 1.21.1, drop the AutoModpack file into your mods folder, then join using the address in step 5. AutoModpack downloads everything else for you.
1

Have Minecraft Java Edition 1.21.1

Open the Minecraft Launcher once and run version 1.21.1 so the game files are downloaded.

2

Install NeoForge 1.21.1

Download the installer for Minecraft 1.21.1 from neoforged.net. Close the launcher, run the installer, choose Install client, and click OK.

Tip: make a separate profile for modded play, in the launcher's Installations tab, with its own game folder, so your normal game stays clean.

3

Add AutoModpack to your mods folder

Download the newest AutoModpack file for NeoForge 1.21.1 from modrinth.com/mod/automodpack. Put the .jar file in the mods folder of your NeoForge profile. Launch it once and the folder appears.

Do not add any other mods yourself. AutoModpack handles them.

4

Start the NeoForge profile

Launch the NeoForge profile and wait until the main menu appears. Then open Multiplayer → Add Server.

5

Enter the server address

Name it anything you like. For the Server Address, copy and paste this whole line, including the part after the #:

chameleon.minecraft.best#amp1=9b792be25f39a88a361c6d506c5e8a8156beb55a5710b7d738eec4061e661cfd

The long part after the #, starting 9b79…, is the AutoModpack server code. It lets AutoModpack confirm this really is our server, so there is nothing else to check.

You can also join with just chameleon.minecraft.best and enter the server code later, when AutoModpack's verification screen asks for it. The code is:

9b792be25f39a88a361c6d506c5e8a8156beb55a5710b7d738eec4061e661cfd
6

Join, accept the download, and restart

Click the server to join. AutoModpack shows the mods it needs. Click to confirm and let it download.

Under Customize you can pick optional extras, such as a brightness toggle, dynamic lights and Macro Keybinds. The required mods are installed no matter what.

When it asks you to restart, close the game and open the same profile again, then join. You are in.

Using Prism Launcher instead?

Create a new instance, choose Minecraft 1.21.1 with the NeoForge loader, put the AutoModpack file in its mods folder, and continue from step 4.

Trouble connecting?

It says the version or mods do not match

Make sure you are running the NeoForge 1.21.1 profile, not plain Minecraft, and that you used the full address from step 5.

It says the server is offline or times out

The server may be restarting. Wait two minutes and try again. If it still fails, message PurpleMonkey439 on Discord.

I do not see an AutoModpack screen

The AutoModpack file is probably in the wrong place. It must be in the mods folder of the NeoForge profile you are launching, and the file must end in .jar.
